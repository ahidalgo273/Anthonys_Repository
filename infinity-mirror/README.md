## Why paused
At the working assumptions (made in China, $60 factory price, $179 retail, 100 units):
- Each Amazon sale loses about $1.71.
- The first order needs about $17,160 cash, over the $15k ceiling.
- Main cause: 44% import duty on Chinese framed mirrors (6.5% base + 25% Section 301 + 12.5% forced-labor duty).

## Restart if any of these become true
1. A factory quotes $50 or less (FOB) for the Rev B spec, so $189 retail clears ~$20/sale.
2. Section 301 duties on China drop, or a Vietnam/India factory can build it near $60.
3. Budget rises to ~$20k.
4. A cheaper Rev C (mirror-acrylic rear strips, simpler LEDs) lands near $45.
